# 课伴AI｜英语课本智能学习助手

面向小学、初中、高中英语学习者的单文件 HTML 产品原型 Demo。项目不依赖前端框架，使用原生 HTML、CSS 和 JavaScript 实现，通过 `div` 显示/隐藏模拟页面路由，使用 `localStorage` 模拟账号、学习状态、会员、订单和客服数据。

## 快速开始

直接打开 [index.html](./index.html) 即可运行，无需安装依赖或启动后端服务。

学情诊断页面使用 Chart.js CDN 绘制雷达图，首次打开时需要网络加载 CDN；即使 CDN 不可用，其余原型页面仍可正常浏览。

## 已实现模块

- 登录、注册、实时表单校验、邮箱验证码模拟、记住密码、忘记密码弹窗、切换账号和退出登录。
- 顶部导航：首页、课本预习、课本复习、作业中心、模拟试卷、会员中心、管理后台。
- 首页单元选择、学习入口卡片、会员状态和今日学习建议。
- 课本预习：课文导读、生词释义、长难句 AI 解读、单词听写、发音检测占位、听力练习。
- 课本复习：知识点回顾、基础检测、单词听写和检测结果。
- 预习、复习、检测完成后展示学习评级、评级依据、错题/易错知识点和短期个性化学习计划。
- 作业中心：作业文本录入、免费版简略批改、VIP 逐题讲解和能力评级展示。
- 学情诊断：词汇、句法、语篇逻辑、写作输出四维 Chart.js 雷达图及错题根因标签。
- 会员中心：月卡 10 元、季卡 20 元、年卡 60 元；支持模拟支付宝收银台和 VIP 到期时间记录。
- VIP 权限拦截：模拟试卷、完整作业讲解和学情诊断对免费用户显示会员引导。
- “我的”个人中心：个人资料、会员状态、学习记录、订单入口、通知开关、修改密码弹窗和清除本地缓存。
- 全局客服悬浮按钮：留言保存到 `localStorage`，管理员后台可查看并标记回复。
- 管理员后台：用户管理、消费记录、客服留言，全部从 `localStorage` 读取。

## 本地数据

主要数据键：

- `keBanAiDemoDB_v1`：用户、订单、客服留言、会员到期时间。
- `keBanAiSession`：当前登录用户名。
- `rememberedPassword`：登录页“记住密码”的演示值。

点击“我的 → 清除本地缓存”会重置 Demo 数据并返回登录页。

## 原型操作流程

1. 使用 `student / 123456` 登录，浏览英语课本预习和复习页面。
2. 完成预习或检测后查看学习评级、错题标签和个性化短期计划。
3. 进入会员中心，选择套餐并依次点击“确认支付”和“模拟支付成功”。
4. 会员开通后访问模拟试卷、作业详细讲解和学情诊断。
5. 点击右下角客服图标提交留言。
6. 退出后使用 `admin / 123456` 登录，进入管理后台查看用户、订单和客服留言。
